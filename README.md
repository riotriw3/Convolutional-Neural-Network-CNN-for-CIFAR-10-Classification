# Convolutional-Neural-Network-CNN-for-CIFAR-10-Classification

## 📌 Project Overview

This project focuses on building a **Deep Learning model that can recognize and classify images** using the CIFAR-10 dataset. The dataset contains 60,000 small color images divided into 10 categories, such as airplanes, cars, birds, cats, dogs, and ships.

In this project, two Deep Learning approaches were explored: **Convolutional Neural Network (CNN)** and **ResNet**. Both models were trained to learn visual patterns from the images and predict the correct category for new images.

## 🔎 Analisa

* Prepared and normalized the CIFAR-10 image dataset.
* Built and trained a **CNN model** to recognize image patterns.
* Built and trained a **ResNet model** as another approach for image classification.
* Evaluated the models using accuracy, loss, and confusion matrix.
* Compared the performance of CNN and ResNet based on the testing results.

## 📊 Results

* **The models learned to recognize images** from CIFAR-10 and classify them into 10 different categories, such as airplanes, cars, cats, dogs, and others.
* **Model performance was evaluated** using accuracy, loss, and confusion matrix to understand how often the models made correct predictions and which images were still difficult to recognize.
* **CNN and ResNet were compared** to understand how different model architectures perform when classifying images.
